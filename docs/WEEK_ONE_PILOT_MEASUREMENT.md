# Week-one opt-in pilot sheet

Use this only with a household's consent. Record a household alias, never its family key, names, recipe text, photos, or private meal history. Keep the sheet outside shared app records; no analytics service or background request is added.

| Session date | Household alias | Planning time (self-reported minutes) | Draft dinners offered | Approved without change | Swapped or edited before approval | Dinner outcomes recorded | Provider calls observed | Provider tokens reported | Notes about friction |
|---|---|---:|---:|---:|---:|---:|---:|---:|---|
|  |  |  |  |  |  |  |  |  |  |

Start timing when the family begins the weekly draft and stop when they finish the separate shopping review. Mark an interrupted session as incomplete rather than inventing a duration. Count approved and changed draft dinners from the person's review, not from an inferred acceptance rate. Count outcomes only when someone actually records dinner feedback. A deterministic session should have zero provider calls; write **unknown** when provider usage cannot be measured, never an estimated zero. If a future optional AI action is tested, record the measured call and token totals separately from cost estimates. Ask what felt confusing in plain language, and keep any quoted feedback anonymous.
